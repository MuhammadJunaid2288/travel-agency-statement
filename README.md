# Travel Agency - Multi-Agent Statement (Web / Online Version)

Browser mein chalne wala software (Streamlit)

## Features
- Multiple Agents (har agent ka alag data)
- Dashboard, Tickets/Packages, Payments
- PDF Statement download
- All Agents overview
- Mobile friendly

## Local pe chalane ka tareeqa

```bash
pip install -r requirements.txt
streamlit run app.py
```

Browser automatically open hoga (http://localhost:8501)

## Online deploy (Free)

1. GitHub pe upload karein
2. https://streamlit.io/cloud pe account banayein
3. App deploy karein — free public URL mil jayegi

Ya Render.com / Railway pe bhi host kar sakte hain.

## QR Code
PDF statement ke neeche QR code automatically generate hota hai.
Scan karne pe Statement No, Agent Name aur Outstanding Balance dikhta hai.
